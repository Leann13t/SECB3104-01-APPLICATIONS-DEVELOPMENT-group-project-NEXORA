
# SECB3104-01 APPLICATIONS DEVELOPMENT – GROUP PROJECT NEXORA

## Project Overview

Nexora is a group project developed for the SECB3104-01 Applications Development course.

## Technology Stack

- Flutter – Mobile application development
- Dart – Programming language
- Supabase – Backend and database
- GitHub – Version control and collaboration
- Android Studio – Android emulator and development tools

## Getting Started

### Prerequisites

Install the following tools:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Visual Studio Code](https://code.visualstudio.com/)
- [Android Studio](https://developer.android.com/studio)
- [Git](https://git-scm.com/)

### Setup Instructions

Clone the repository:

```bash
git clone https://github.com/Leann13t/SECB3104-01-APPLICATIONS-DEVELOPMENT-group-project-NEXORA.git
```

Navigate into the project:

```bash
cd SECB3104-01-APPLICATIONS-DEVELOPMENT-group-project-NEXORA
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

## Backend Setup

This project uses Supabase with the `supabase_flutter` package.

Each developer should obtain the project's connection details from the project team.

Never commit database passwords or Supabase secret/service_role keys to GitHub.
